# kabirinvents.com

The portfolio site for Kabir Gagneja (Kabir Invents), live at https://kabirinvents.com/

This is a single static page (index.html) with its images in assets/.

## Top banner

A yellow banner at the very top of the page links to Ko-fi: "Support me on these projects via Ko-fi" (https://ko-fi.com/kabirinvents).

## Deploying

This repo is the source of the site. To make changes live, link the Vercel project for kabirinvents.com to this repo, or deploy this folder to Vercel.
