# kabirinvents.com

The portfolio site for Kabir Gagneja (Kabir Invents), live at https://kabirinvents.com/

This is a single static page (index.html).

## Top banner

A yellow banner at the very top of the page links to Ko-fi: "Support me on these projects via Ko-fi" (https://ko-fi.com/kabirinvents).

## Images

The page needs two images in an assets/ folder next to index.html:
- assets/avatar.jpg (the profile photo, 320x320)
- assets/kabirui-icon.png (already in this repo at assets/kabirui-icon.png)

avatar.jpg still needs to be added by hand (drag and drop it into the portfolio/assets folder on GitHub) because binary uploads are not possible through the current GitHub connection.

## Deploying

To make changes live, link the Vercel project for kabirinvents.com to this folder, or deploy this folder to Vercel.
